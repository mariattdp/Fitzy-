# Fitzy — site demonstrativo

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Para editar, use um editor como VS Code e mantenha os três arquivos na mesma pasta.

## Arquivos
- `index.html`: estrutura e conteúdo do site.
- `style.css`: identidade visual responsiva em rosa, com estética girly.
- `script.js`: menu mobile e demonstração interativa de sugestão de looks.

## Observação
O site é um protótipo front-end. O formulário gera sugestões demonstrativas no navegador; não há cadastro real, banco de dados, IA conectada, pagamentos ou publicação em lojas de aplicativos.
